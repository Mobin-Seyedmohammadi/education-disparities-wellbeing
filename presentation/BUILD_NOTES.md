# Seminar presentation

The editable deck presents the standalone research study. Speaker notes contain numerical provenance, source links and interpretation details.

The standard Python pipeline rebuilds the scientific figures and tables and the PDF paper. To update the talk, edit the PPTX in PowerPoint or LibreOffice and replace figures and numbers using the regenerated outputs.

The deck uses DejaVu Sans. Font files and their license are bundled in `assets/fonts/`. Installing the font preserves the intended typography when editing on another computer.
